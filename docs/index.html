The Salience of Data

MBI Deep Dives · 2026-07-11 · ⏱ 8 min read

MBI Deep Dives uses a veil-of-ignorance thought experiment to argue that proprietary data — not compute, talent, or architecture — is the primary source of sustainable moat for frontier AI model companies. The piece traces Anthropic's coding dominance to a data flywheel built on focused product-market fit, while examining whether xAI's Cursor acquisition could replicate or surpass that flywheel. It synthesizes perspectives from OpenAI engineers to argue that model behavior is fundamentally dataset-determined, making data accumulation the central strategic variable.

💡 For an investor evaluating AI infrastructure and health data companies, this piece provides a rigorous mental model for assessing which data flywheels are defensible — directly applicable to diligence on AI-native platforms where proprietary data accumulation is the core moat thesis.
