An OpenAI model has disproved a central conjecture in discrete geometry

Hacker News · 2026-05-21 · ⏱ 6 min read

OpenAI's general-purpose reasoning model has autonomously disproved the Korkine-Zolotareff conjecture in discrete geometry, a problem that has stood for nearly 80 years. The AI found a construction that achieves polynomial improvement over previously known bounds for the planar unit distance problem, using sophisticated techniques from algebraic number theory. This marks the first time a prominent open mathematical problem has been solved autonomously by AI.
